A) Regenerate Pickup Code RPC ✅
Migration: infra/supabase/migrations/20250115000005_regenerate_pickup_code.sql
- RPC: regenerate_pickup_code(p_order_id) RETURNS TEXT
  - Verify merchant owns order and status IN ('PENDING_COURIER', 'WAITING_PICKUP')
  - Generate new 6-digit code: LPAD(FLOOR(RANDOM() * 1000000)::TEXT, 6, '0')
  - Update orders.pickup_code, log to order_events
  - GRANT EXECUTE TO authenticated
- Service layer: OrderService.regeneratePickupCode(orderId) -> String?
  - Calls RPC regenerate_pickup_code
  - Fallback: Returns null if RPC doesn't exist or fails
