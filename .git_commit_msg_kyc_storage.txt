- File picker/camera integration:
  - packages/supabase_client/pubspec.yaml: Added file_picker ^8.0.0, image_picker ^1.0.7
  - apps/courier_app/lib/features/kyc/presentation/kyc_flow_page.dart:
    - Web: FilePicker.platform.pickFiles(type: FileType.image)
    - Mobile: ImagePicker.pickImage(source: camera/gallery) with dialog choice
    - Read fileBytes and extension
    - Upload flow: Pick/capture → Toast "上傳中..." → StorageService.uploadKYCDocument

  - uploadKYCDocument: Actual storage.from('kyc-documents').uploadBinary()
  - FileOptions: upsert=true, contentType=image/*
  - Returns public URL on success, null on failure
  - Error handling: Bucket not created → null (UI shows error Toast)

  - infra/supabase/migrations/20250115000001_storage_buckets.sql

    1. kyc-documents (private, 5MB, image/jpeg|png|jpg)
    2. order-photos (private, 10MB, image/jpeg|png|jpg)
    3. menu-photos (public, 5MB, image/jpeg|png|jpg)
